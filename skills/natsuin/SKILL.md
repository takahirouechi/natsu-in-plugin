# ナツ印（NATSU-in）

ナツ印は、Mac のナツ印のアプリが描く、日付入りの丸い印影（上段・日付・下段の3段）の画像を渡す。見た目としての画像で、確認した事実を証明するものではない。

## 使うとき

- 本人が合言葉「ナツ印」と言ったら、道具 `natsuin` を呼ぶ。頼まれたこと自体を本人の判断とみなし、重ねて確かめない。
- 「捺印して」「ハンコを押して」だけで「ナツ印」と言われていないときは、ナツ印を使うか本人に確かめる。

## 呼び方

1. ふだんは `save_to` なしで呼ぶ。印影がクリップボードに入るので、「貼り付け（⌘V）で貼れます」と伝える。
2. ファイルで欲しいと言われたら、`save_to` に Mac の上のフォルダ（または `.png` の名前）を入れる。`stamp_YYYYMMDD.png` ができる。同じ名前があれば上書きせず「 (2)」が付く。
3. 日付は、本人がはっきり言ったときだけ今日以外にする（`yesterday`・`day_before_yesterday`・`YYYY-MM-DD`）。あいまいなら本人に確かめる。
4. たくさんの日付が要るとき（議事録ごとの開催日など）は、日付ごとに `natsuin` を `save_to` つきで繰り返し呼ぶ。同じ日付は 1 つで足りる。

## してはいけないこと

- ナツ印の仕事は印影の画像を渡すところまで。ナツ印は書類を読まず、書き換えない。
- 印影を使ったことを、承認や送信が済んだように言わない。印影を、何かを証明するもののように呼ばない（見た目としての画像）。
- 上段・下段の文字（氏名など）を、頼まれていない場所に書き写さない。

## 道具が見つからないとき

- 「ナツ印のアプリが見つかりません」：App Store から Mac のナツ印を入れてもらう。
- 道具 `natsuin` そのものが無い（ふだんのチャットなど）：プラグインの中の道具は Cowork（自分の Mac で動くとき）と Claude Code で動く。ふだんのチャットで使うには、natsu-in.com の `.mcpb` を Claude Desktop に入れてもらう。
